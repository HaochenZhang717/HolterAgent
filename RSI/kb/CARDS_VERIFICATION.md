# Verification log for `cards.json` (2026-10-14)

## How sources were opened and checked

- **PubMed abstracts.** The PubMed web pages (pubmed.ncbi.nlm.nih.gov) returned a JavaScript cookie/proof-of-work challenge to both curl and WebFetch. It was not bypassed. Abstracts were read through the official NCBI E-utilities API instead (`efetch.fcgi?db=pubmed&id=<PMID>&rettype=abstract&retmode=text`); that URL is recorded in each abstract card. Each record was fetched once as XML in a batch and once as plain text for the single PMID.
- **PMC full text.** Direct download of PMC pages returned a reCAPTCHA page. It was not bypassed. Europe PMC `fullTextXML` returned HTTP 500 for these articles, and NCBI efetch (db=pmc) said the publisher does not allow XML download. The PMC article pages were then read with WebFetch, which did load the article text. WebFetch answers through a model and will not return more than 125 characters of verbatim text, so each quote was confirmed with a yes/no exact-match check. Quotes longer than 125 characters were confirmed in two pieces that overlap, which also shows they are contiguous.
- **Other full text.** ACC/AHA 1999: the Wayback copy of onlinejacc.org (snapshot 2010-01-22), downloaded with curl and searched locally. Jager 2003 (LTSTDB paper): PhysioNet HTML, downloaded with curl and searched locally. ESC 2019: academic.oup.com HTML via WebFetch; the recommendation tables are images, so only running text was used. JCS 2013: J-STAGE HTML (digest version) via WebFetch.
- **Automated checks** (`validate_cards.py`, kept in the session scratchpad, not in the repo):
  - schema and topic keys;
  - word limits (title 12, statement 70, quote 25, applies_when 30, limits 30);
  - quote present verbatim in the locally saved source text, after normalising whitespace and Unicode hyphen/quote glyphs;
  - every number in the statement present in the source text.
- **Results of the automated checks.** 27 cards passed everything automatically. In the other 18, every remaining flag was resolved by hand:
  - numbers printed as words in the source (for example 'Twenty-one patients');
  - symbols that are images in the HTML (≤, ≥, min⁻¹), checked against the alt text in the raw HTML;
  - WebFetch-confirmed full-text quotes.
- **Statement wording.** Statements were written as paraphrases and then compared with the source sentence by sentence.
- **Numbers not used.** No number marked [LOCAL] in the research notes was used, and no statistic computed on LTSTDB labels (train or test) was used.
- **Notes as leads only.** The research notes and report served only as leads. Every quote and number was re-checked against the source text opened in this task.

## Discrepancies noticed while verifying

- **Bjerregaard 2003.**
  - The abstract gives 16 (24%) patients with events at J+80, 10 (15%) when J-point depression is also required, and 3 (4.5%) after baseline correction. The Discussion says the baseline correction reduced patients with events 'from 14 (21%) to only 3 (4.5%)'. The card uses the abstract figures.
  - The 227 -> 136 episode count is the PR-(J+80) count in Table 2, before and after positional changes were excluded (WebFetch answer). It is not stated in the abstract.
- **Stern 2014.** The abstract gives two totals: 9,200 consecutive cases and 8,300 examinees. Recorded in the card's limits.
- **ESC 2019.** The research notes quoted the vasospasm recommendation 'in the absence of increased heart rate' from a table image, which could not be read as text here. The card (K29) instead uses the running-text sentence 'ST-segment shifts at normal heart rate supports ...'. For SVT, the notes quoted a Class III table line; K33 uses the running-text sentence in section 3.1.3.2.
- **Panza 1992 (PMID 1401608).** The full abstract (387 words, not truncated) was available through E-utilities. The report had marked the 89% figure as coming from an earlier survey.
- **Andrews 1993 vs Panza 1992.** 81% of episodes were preceded by a rise of >=5 bpm (Andrews) and 89% by a rise of >=10 bpm (Panza). The definitions and populations differ, so the two figures should not be merged.
- **JCS 2013.** The J-STAGE page is the 'Digest Version' of the guideline (Circ J 2014;78:2779-801). The source string says so.
